## Dead Zone: Polymorphism

## Overview:

Dead Zone: Polymorphism is a text-based RPG adventure game developed in Python using Object-Oriented Programming (OOP). Set during a zombie apocalypse, players must survive by exploring dangerous locations, collecting supplies, fighting infected enemies, and escaping the city before time runs out. The game was created as part of a Year 11 Software Engineering project and demonstrates key OOP concepts including classes, objects, inheritance, encapsulation, abstraction, and polymorphism.

## Story:

A deadly virus has spread across the city, turning humans into violent infected creatures. You are one of the last survivors left alive.

### To escape, you must:
* explore abandoned locations
* collect supplies and weapons
* survive zombie encounters
* unlock the evacuation zone
* make choices that affect your survival

Every decision matters.


## Features:

* Text-based RPG gameplay
* Multiple explorable locations
* Inventory system
* Zombie combat system
* Different zombie types
* Health and healing mechanics
* Story progression and objectives
* Object-Oriented Programming structure
* Interactive command system

## OOP Concepts Used:
| OOP Concept | Example in Game |
| ----------- | --------------- |
| Classes | Player, Zombie, Item, Location |
| Objects | Weapons, zombies, rooms |
| Inheritance | FastZombie and TankZombie inherit from Zombie |
| Encapsulation | Player health and inventory handled through methods |
| Abstraction | User interacts through simple game commands |
| Polymorphism | Different zombies use the same attack method differently |

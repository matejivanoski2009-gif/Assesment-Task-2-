# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

1. **Do NOT open a public issue.** Security vulnerabilities should be disclosed privately to ensure users are protected until a patch is released.
2. **Contact Us:** Send an email detailing the vulnerability to `matejivanoski2009@gmail.com` (or open a [Draft Security Advisory](https://docs.github.com/en/code-security/repository-security-advisories/creating-a-repository-security-advisory) directly on GitHub).

### What to Expect

- **Acknowledgement:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** Our team will review and attempt to reproduce the reported issue. We will update you on our findings within 5 business days.
- **Resolution:** If accepted, we will work on a fix and release a security update. We will coordinate the public disclosure date with you.
- **Public Disclosure:** Once a patch is released, we will credit you in the release notes or security advisory (unless you prefer to remain anonymous).
